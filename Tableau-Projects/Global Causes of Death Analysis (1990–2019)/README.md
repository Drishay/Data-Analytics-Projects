# 🌍 Global Causes of Death Analysis Dashboard (1990–2019)

An interactive **Tableau Dashboard** that analyzes global mortality data across countries, diseases, and time to uncover key health trends and insights.

---

## 🚀 Overview

This project focuses on analyzing **global causes of death from 1990 to 2019** using data visualization techniques.

The dashboard transforms complex health data into **interactive and meaningful insights**, helping users understand:
- Major causes of death worldwide  
- Country-wise comparisons  
- Trends over time  

---

## 🎯 Features

- 🌐 Global disease distribution (Map Visualization)
- 📊 Top 10 deadliest diseases worldwide
- 📈 Death trends over time (1990–2019)
- 🌍 Country-wise death comparison
- 🔥 Disease heatmap across countries
- 🎛️ Interactive filters:
  - Year  
  - Country  
  - Disease category

## 📊 Dataset

- Covers **30 years of data (1990–2019)**  
- Includes **200+ countries/regions**  
- Multiple **disease categories and causes of death**  

---

## 📊 Key Insights

- Cardiovascular diseases are among the **leading causes of death globally**
- Countries like **India, China, and the USA** contribute significantly to total deaths
- Death trends show **consistent patterns across decades**
- Disease impact varies significantly across regions
